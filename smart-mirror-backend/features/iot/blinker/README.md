# BlinkerAPP与树莓派局域网通信实现

## 实现概述
本项目实现了BlinkerAPP与树莓派之间的局域网通信功能，支持远程控制和数据上报。

## 文件说明

### 1. blinker_raspberrypi.py
树莓派端主通信脚本，包含以下功能：
- 基础Blinker初始化配置
- 局域网通信模式设置
- 按钮控制回调函数
- GPIO LED控制
- 温度数据上报
- 异常处理和资源清理

### 2. blinker.service
系统服务配置文件，用于实现脚本开机自启动。

## 使用步骤

### 1. 环境准备
确保树莓派已安装Python 3.6+，并安装所需依赖：
```bash
pip3 install blinker mqtt
```

### 2. 获取设备密钥
1. 打开BlinkerAPP，点击右上角"+"添加设备
2. 选择"独立设备" → "网络接入" → "局域网"
3. 记录生成的设备密钥

### 3. 配置脚本
编辑`blinker_raspberrypi.py`文件，修改以下内容：
- 将"设备密钥"替换为实际获取的密钥
- 将"树莓派IP地址"替换为树莓派的实际局域网IP

### 4. 运行脚本
```bash
python3 blinker_raspberrypi.py
```

### 5. APP配置
1. 进入设备列表，选择已创建的局域网设备
2. 点击右上角"设置" → "设备设置" → "局域网设置"
3. 输入树莓派的局域网IP地址和端口（默认8080）
4. 设计控制界面，确保组件ID与脚本中注册的ID一致（如btn-abc）

### 6. 配置开机自启（可选）
将`blinker.service`文件复制到树莓派的`/etc/systemd/system/`目录下，然后执行：
```bash
sudo systemctl enable blinker
sudo systemctl start blinker
```

## 功能说明

### 按钮控制
- APP端按钮控制LED开关
- 支持状态反馈

### 数据上报
- 每2秒自动上报温度数据
- 支持自定义传感器数据上报

## 故障排除
- 检查IP地址和端口是否正确
- 确保设备密钥匹配
- 验证APP组件ID与脚本中注册的ID一致
- 查看终端输出日志定位问题

## 安全建议
- 为树莓派设置固定IP地址
- 考虑使用数据加密传输（Blinker Pro支持）
- 定期更新依赖库

## 注意事项
- 脚本中使用的GPIO引脚为BCM模式下的18号引脚
- 实际使用时需根据硬件连接情况调整GPIO引脚配置
- 真实传感器数据需替换示例中的模拟数据
