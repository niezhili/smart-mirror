# 前端液态玻璃重构说明

## 目标
本次重构统一采用苹果风格的液态玻璃视觉语言，后续新增模块也必须遵循同一套视觉规范与交互约定。

## 全局设计要求
- 所有模块使用统一的玻璃面板样式：半透明、模糊背景、高光描边、柔和投影。
- 所有模块文字颜色根据当前背景亮暗自动切换，保证在深浅壁纸下都具备可读性。
- 背景图上方增加全局压暗层，降低高亮壁纸对前景文字的干扰。
- 模块间风格保持一致：圆角、描边、景深、层次和动效必须统一。

## 模块重构范围

### 1. 日期与时间模块（MMM-Clock）
- 改为苹果风数字时钟样式。
- 时间字体放大、加粗、层级更强。
- 日期与时间信息置于玻璃容器中。
- 去除刷新时文字颜色黑白闪烁的问题，改为稳定的主题色变量驱动。
- 删除秒级显示（数字秒与模拟秒针），统一为小时与分钟，降低视觉噪声。
- 刷新策略改为按分钟边界更新，且禁用更新动画，避免每次更新时间出现闪烁。

### 2. 新闻模块（MMM-News）
- 外层增加液态玻璃边框容器。
- 一次显示十条新闻，支持纵向滚动查看。
- 增加新闻类别切换，例如热点、推荐、体育、国际、科技等。
- 通过左右滑动切换类别。

### 3. 语言切换模块（MMM-Language）
- 默认单击在中文与英文之间切换。
- 长按弹出语言列表，可选择中文、英文、法语、日语、韩语、西班牙语等。
- 列表本身使用同一套玻璃面板样式。

### 4. 背景模块（MMM-Background）
- 在背景图上叠加暗色蒙层。
- 每小时自动切换壁纸。
- 用户可在空白区域左右滑动手动切换壁纸。
- 背景模块负责输出全局主题亮度信息，供其他模块自动选择文字颜色。

### 5. Quotes 模块（MMM-Quote）
- 新建完整模块实现，不再依赖空目录占位。
- 数据结构由本仓库维护，至少包含 `quote`、`author`、`category` 字段。
- 提供分类视图，例如名人经典语录、谚语、格言。
- 语录库构建基于联网调研后整理的本地静态数据，优先采用稳定、可控的方式，避免运行时依赖外部接口失效。

## 渲染稳定性修复（2026-04）

### 清理清单
- 删除 MMM-Background 中“每次切图都整块 `updateDom`”的旧路径。
- 删除 MMM-Quote 中“定时器触发整块 `updateDom`”的旧路径。
- 删除 MMM-Calendar 中“每分钟整块 `updateDom`”的旧路径。

### 冲突说明
- 旧逻辑在背景层会触发全屏 DOM 重建，重建间隙会短暂露出底色，表现为黑屏闪烁。
- Quote/Calendar 的定时刷新属于小数据变化，不应该每次重建完整结构，否则会带来可见闪烁与不必要开销。

### 新旧对比
- 旧逻辑：定时器或壁纸请求一到就全量重绘。
- 新逻辑：优先原位更新已有节点，只在必要时重绘（例如日期跨天）。

### 伪代码
```text
背景模块:
	预加载下一张图
	预加载成功后直接替换当前 img/src 与容器背景
	若服务端返回集合未变化，则不触发切图

Quote 模块:
	首次 getDom 创建节点缓存
	定时刷新仅更新 quote 文本、作者与分类高亮

Calendar 模块:
	每分钟检测当前日期
	若同一天 => 不重绘
	若跨天/跨月 => 重绘一次
```

## 翻译重构蓝图

### 目标
- 全局显示文案统一走 MagicMirror 标准翻译链路：`getTranslations()` + `this.translate()`。
- 语言切换只负责维护当前语言状态，不再在业务模块内部写 `中文/英文` 条件分支。
- 配置层只传语义 key 或数据 key，不再直接传最终展示文案。

### 拟删除清单
- MMM-News 中写死的面板标题、滑动提示、空态提示、匿名来源文案。
- MMM-Quote 中写死的分类展示名与空态提示。
- MMM-DHT11 中基于语言值手动二选一的温湿度标签。
- MMM-Weather 中未接入翻译文件的加载态、错误态和详情标签。
- MMM-Clock 中固定英文 `Week` 标签。
- config.js 中传给模块的中英文展示文案。

### 冲突说明
- 旧实现把翻译逻辑散落在模块内部，语言新增或切换时需要逐个模块改条件，容易遗漏。
- 同一个仓库同时存在配置层硬编码、模块层硬编码、翻译文件三套来源，优先级不清晰。

### 新旧对比
- 旧逻辑：模块直接渲染中文或英文字符串，或根据 `config.language` 手写条件判断。
- 新逻辑：模块只渲染翻译 key，对应文案由当前语言文件解析；语言模块只负责切换 `config.language/config.locale`。

### 伪代码
```text
输入: 当前语言 code

language 模块读取并持久化当前语言
config.js 将 language/locale 注入全局配置

每个业务模块:
	定义 getTranslations()
	渲染时调用 this.translate(key, fallback)
	配置层仅提供 labelKey / dataCategory / panelTitleKey 等语义字段

输出: 所有显示文案随当前语言统一切换
```

## 技术约定
- 优先修改现有模块，不无谓引入框架。
- 使用 CSS 变量统一玻璃质感、描边、阴影与文字颜色。
- 背景与前景模块之间通过 DOM 主题变量或通知共享亮度状态。
- 新增模块需要兼容 MagicMirror 当前模块加载方式。
